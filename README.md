# Навигатор мер поддержки

Интерактивный навигатор мер государственной поддержки — статическая веб-страница, собранная в Claude Design. Всё приложение (разметка, стили, скрипты и данные) упаковано в один самодостаточный файл [`index.html`](index.html).

## Демо

После настройки GitHub Pages (см. ниже) сайт будет доступен по адресу:

```
https://<ваш-логин>.github.io/navigator-web/
```

## Запуск локально

Никакой сборки не требуется — это статическая страница. Достаточно открыть `index.html` в браузере.

Либо поднять локальный сервер (рекомендуется, чтобы корректно подгружались шрифты):

```bash
# Python 3
python -m http.server 8000
# затем открыть http://localhost:8000
```

## Деплой на GitHub Pages

Репозиторий уже содержит workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml), который автоматически публикует сайт при каждом пуше в ветку `main`.

Что сделать один раз после создания репозитория на GitHub:

1. Запушить эту папку в репозиторий `navigator-web`.
2. Открыть **Settings → Pages**.
3. В разделе **Build and deployment** выбрать **Source: GitHub Actions**.
4. Дождаться завершения workflow во вкладке **Actions** — после этого сайт станет доступен по ссылке выше.

> Альтернатива без Actions: в **Settings → Pages** выбрать **Deploy from a branch → `main` / `(root)`**. Тогда файл workflow можно удалить.

## Зависимости

Внешних зависимостей нет, кроме шрифтов Google Fonts, которые подгружаются по сети при открытии страницы.

## Происхождение

Страница экспортирована из [Claude Design](https://claude.ai/design) как handoff-бандл и представляет собой рабочий прототип.
